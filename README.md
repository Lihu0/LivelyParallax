# Lively Parallax

<img src="preview.gif" width="400" />

**Lively Parallax** is a simple parallax wallpaper for [Lively Wallpaper](https://www.rocksdanister.com/lively/).

## Usage

1. Install [Lively Wallpaper](https://www.rocksdanister.com/lively/) by rocksdanister.
2. Download the latest `.zip` wallpaper from the _Releases tab_.
3. Click the "plus" symbol on the Lively app.
4. Drag & drop the `.zip` file or choose it.

> [!TIP]
> Click the edit button on the wallpaper and don't change any setting to force reset the preview.

## Features

- Custom image background.
- Control the speed of the parallax and other options.
- Background parallaxes to your mouse.
- Background panning animation.
- More lightweight compared to the original rain version.
